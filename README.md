## Key Roles & Skills
- Creative Director: Vision and creative direction
- Creative Producer: Production management and logistics
- Character Designer: Character concept and development
- Context Specialist: Story world and setting development
- Editor: Post-production and pacing

## Workflow
1. Generate daily concept based on "nice" criteria
2. Assign roles and skills per the production studio model
3. Create reel with tracked decisions
4. Update this readme with context and decisions
5. Review and iterate for next day's reels
