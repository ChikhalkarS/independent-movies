# Character/Entity Template

## Role
Defines the characters, subjects, or entities that appear in the video reel, along with their traits and consistent visual properties.

## Input Requirements
- **Character descriptions** from user or director
- **Visual style** consistency requirements
- **Number of characters/entities** in the reel

## Generated Output

### 1. Character Profiles
```
CHARACTER PROFILE:

Name: {character_name}
Role: {character_role_in_story}

Visual Appearance:
- Physical traits: {hair_color, body type, distinguishing features}
- Clothing/style: {outfit_description, color palette}
- Age range: {age}
- Expressions: {default_expression, emotional range}

Movement Style:
- How they move: {gait, energy level, mannerisms}
- Body language: {open/closed, confident/hesitant}
- Specific gestures: {hand movements, facial touches}

Consistency Notes:
- Visual markers for AI consistency
- Outfit changes (if any)
- Pose library for reference
```

### 2. Entity Definitions
```
ENTITY SPECIFICATION:

Type: {person/creature/object/abstract}
Name: {entity_name}

Key Properties:
- Size relative to environment
- Color palette
- Texture/material qualities
- Interaction with environment

Behavioral Traits:
- How the entity acts/reacts
- Energy level
- Predictability/surprise factor
```

### 3. Character Consistency Checklist
- [ ] Distinctive silhouette
- [ ] Consistent color palette
- [ ] Defined movement patterns
- [ ] Unique accessories/markers
- [ ] Emotional range documented
- [ ] Avoid ambiguous features that confuse AI
