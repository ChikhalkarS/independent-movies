# Context/World Template

## Role
Defines the story world, setting, and environmental context for the video reel generation.

## Input Requirements
- **Setting description** from user/director
- **Time period/era**
- **Location details**
- **Atmosphere/mood**

## Generated Output

### 1. World Building
```
WORLD BUILDING:

Setting: {primary_location}
Time period: {era or time of day}
Season/weather: {conditions}

Environmental Details:
- Key landmarks or props
- Architectural style
- Natural elements (sky, ground, vegetation)
- Urban vs. rural, indoor vs. outdoor

Atmosphere & Mood:
- Primary emotional tone
- Lighting quality (time of day, weather effects)
- Color grading style
- Sensory details (sounds, smells, texture feel)
```

### 2. Scene Context
```
SCENE CONTEXT:

Scene location: {specific place within setting}
Scene purpose: {what this scene achieves}
Story moment: {flashback, climax, establishing shot, etc.}

Time of day: {specific time}
Weather conditions: {affecting mood and lighting}
Lighting scheme: {key light, fill, backlight, practicals}
```

### 3. World Consistency Checklist
- [ ] Clear primary setting established
- [ ] Temporal context (time/day/season)
- [ ] Atmospheric mood defined
- [ ] Lighting scheme specified
- [ ] Key props/landmarks identified
- [ ] Sensory details documented for AI consistency
