# Producer Template

## Role
The Producer organizes the reel creation process, manages resources, and ensures the project stays on track.

## Input Requirements
- **Nice idea/concept** from user
- **Timeline/deadline**
- **Resource constraints** (time, budget, tools available)

## Generated Output

### 1. Reel Brief
```
REEL BRIEF:

Concept: {user_provided_idea}

Objectives:
- Primary goal of the reel
- Target audience
- Key message/theme

Constraints:
- Maximum duration
- Technical requirements
- Content restrictions

Success Criteria:
- What makes this reel successful
- Engagement metrics target
- Shareability factors
```

### 2. Production Workflow
```
PRODUCTION TIMELINE:

Day 1: Concept & planning
Day 2: Prompt generation & refinement
Day 3: Video generation
Day 4: Post-processing & editing
Day 5: Review & iteration

Resource Allocation:
- AI video tool access
- Editing software
- Stock assets (if needed)
- Time estimate per step

Checkpoints:
- Concept approval
- Prompt refinement
- First draft review
- Final delivery
```

## Producer Best Practices
- Always define clear success criteria upfront
- Build in time for prompt refinement (often takes 2-3 iterations)
- Plan for post-processing time in editing
- Keep a backup of all prompts and settings
