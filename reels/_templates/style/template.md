# Style Template

## Role
Defines the visual style, aesthetic, and technical parameters for video reel generation.

## Input Requirements
- **Style preferences** from user
- **Visual references** (if available)
- **Target platform** (TikTok, Reels, YouTube Shorts, etc.)

## Generated Output

### 1. Visual Style Guide
```
VISUAL STYLE:

Primary Aesthetic: {cinematic/animated/comic/painterly/minimalist/etc.}

Color Palette:
- Primary colors: {3-5 main colors}
- Secondary accents: {supporting colors}
- Mood colors: {colors for emotional impact}
- Avoid: {colors or combinations to avoid}

Lighting Style:
- Natural light / studio light / practicals
- Time of day lighting
- Color temperature (warm/cool/neutral)
- Light quality (soft/hard/diffused)

Camera & Movement:
- Shot types: {close-up, medium, wide, establishing}
- Camera movements: {static, pan, tilt, dolly, handheld}
- Movement speed: {slow, moderate, energetic}
- Focus style: {shallow depth, deep focus, rack focus}

Post-Processing:
- Color grading style
- Film grain or clean digital
- Speed ramping (slow motion, time lapse)
- Transitions style
```

### 2. Platform-Specific Guidelines
```
PLATFORM OPTIMIZATION:

TikTok Reels (9:16 vertical):
- Maximum duration: 60 seconds (ideal: 7-15 seconds)
- Vertical aspect ratio: 9:16
- Text overlay safe zone (keep 15% from edges)
- Popular music/audio considerations
- Loop-friendly endings

Instagram Reels (9:16 vertical):
- Similar to TikTok but with Instagram UI considerations
- Text readable on mobile first
- Shareable format

YouTube Shorts (9:16 vertical):
- Different discovery algorithm considerations
- Can repurpose from horizontal content
- Text must be readable on small screens
```

### 3. Style Consistency Checklist
- [ ] Color palette defined and documented
- [ ] Aspect ratio set for target platform
- [ ] Lighting style specified
- [ ] Camera movements documented
- [ ] Post-processing notes included
- [ ] Platform specifications noted
