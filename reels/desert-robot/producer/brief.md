# Producer Brief

## Role
The Producer organizes the reel creation process, manages resources, and ensures the project stays on track.

## Input
- **Nice idea**: "A lonely robot finding a flower in a desert"
- **Timeline**: 5-day workflow
- **Resource constraints**: AI video tool access, editing software

## Generated Output

### 1. Reel Brief

```
REEL BRIEF:

Concept: A lonely robot finding a flower in desert

Objectives:
- Primary goal: Evoke emotion of hope in desolation
- Target audience: Viewers seeking emotional, shareable content
- Key message: Hope can be found even in isolation

Constraints:
- Maximum duration: 8 seconds
- Technical requirements: Vertical 9:16, 1080p, 24fps
- Content restrictions: No people, animals, modern technology

Success Criteria:
- Viewer feels moved by the robot's action
- High shareability on social media platforms
- Consistent visual style throughout
```

### 2. Production Workflow

```
PRODUCTION TIMELINE:

Day 1: Concept & planning
Day 2: Prompt generation & refinement
Day 3: Video generation
Day 4: Post-processing & editing
Day 5: Review & iteration

Resource Allocation:
- AI video tool access (Runway, Pika, or similar)
- Editing software for post-processing
- Time estimate: 2 hours per day per reel

Checkpoints:
- Concept approval (Day 1)
- Prompt refinement (Day 2)
- First draft review (Day 3)
- Final delivery (Day 5)
```
