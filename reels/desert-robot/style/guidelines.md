# Style Guidelines

## Role
Defines the visual style, aesthetic, and technical parameters for video reel generation.

## Input
- **Style preferences**: Cinematic realism
- **Target platform**: TikTok/Instagram Reels (vertical 9:16)
- **Visual references**: Cinematic golden hour desert scenes

## Generated Output

### 1. Visual Style Guide

```
VISUAL STYLE:

Primary Aesthetic: Cinematic realism

Color Palette:
- Primary colors: Warm orange (sunset), deep blue (shadows), golden yellow (highlights)
- Secondary accents: Soft white (clouds/highlights), earth brown (ground)
- Mood colors: Melancholic purple (shadow areas), hopeful yellow (flower highlights)
- Avoid: Bright neon colors, pure black (use very dark blue instead), cool dominant blues

Lighting Style:
- Natural light: Golden hour sunlight, warm and directional
- Time of day lighting: Sunset, low angle sun
- Color temperature: Warm (3200K-4000K)
- Light quality: Soft diffuse with hard shadows, typical of sunset

Camera & Movement:
- Shot types: Wide establishing shot, medium close-up on robot/flower
- Camera movements: Slow dolly left to right, subtle tilt down toward flower
- Movement speed: Slow, deliberate, intentional
- Focus style: Shallow depth of field - robot and flower in focus, background softly blurred

Post-Processing:
- Color grading style: Warm tint overall, slightly desaturated highlights
- Film grain: Light grain addition for cinematic feel (10% intensity)
- Speed ramping: None (consistent motion throughout)
- Transitions style: None (single continuous shot)
```

### 2. Platform-Specific Guidelines

```
PLATFORM OPTIMIZATION:

TikTok Reels (9:16 vertical):
- Maximum duration: 60 seconds (ideal: 7-15 seconds) → Using 8 seconds
- Vertical aspect ratio: 9:16 ✓
- Text overlay safe zone: Keep 15% from edges (no critical text)
- Popular music/audio considerations: Soft ambient sounds, no dialogue needed
- Loop-friendly ending: Natural wind-down at end of 8 seconds

Instagram Reels (9:16 vertical):
- Similar to TikTok but with Instagram UI considerations ✓
- Text readable on mobile first ✓
- Shareable format ✓

YouTube Shorts (9:16 vertical):
- Different discovery algorithm considerations
- Can repurpose from horizontal content
- Text must be readable on small screens

Style Consistency Checklist:
- [ ] Color palette defined and documented ✓
- [ ] Aspect ratio set for target platform (9:16) ✓
- [ ] Lighting style specified (golden hour) ✓
- [ ] Camera movements documented (slow dolly) ✓
- [ ] Post-processing notes included (warm tint, light grain) ✓
- [ ] Platform specifications noted (TikTok/Reels 9:16) ✓
```
